# The Long Balance — the site

A single static page for the game, in the game's own design language: ink on paper, a serif
that matches the app's Charter, and the same palette the valley is drawn in.

Every screenshot here is a real frame from a real build, taken with the app's own scripted
screenshot hooks — no mock-ups and no renders. `hero-hearth.jpg` is the standing view at the
hearth; the rest are the shipped App Store set.

Deployed to Vercel from this repository's default branch.
